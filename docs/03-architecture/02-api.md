## 1. Сущности

**Мем (Meme)**

| Поле | Бизнес-описание                                    | Пример значения      |
|------|----------------------------------------------------|----------------------|
| id | Уникальный идентификатор мема                      | 1, 2, 3              |
| title | Название мема                                      | "Грустный кот"       |
| imageUrl | Путь к файлу изображения                           | "/uploads/cat.jpg"   |
| tags | Ключевые слова для поиска (через запятую)          | "кот, грусть, дождь" |
| authorId | Идентификатор автора (email или ID пользователя)   | "user@example.com"   |
| createdAt | Дата и время добавления                            | "2024-01-15T14:30:00" |

## 2. Бизнес-функции (методы)

**CRUD для мемов**

### 2.1. `meme.create` - Создание нового мема
- **Бизнес-правило:** Только авторизованные пользователи могут создавать мемы
- **Ограничения:**
   - Минимум 1 символ в названии
   - Максимум 100 символов в названии
   - Изображение не более 5 МБ
   - Допустимые форматы: JPG, PNG, GIF
- **Входные данные:** изображение (файл), title (строка), tags (строка, опционально)
- **Выходные данные:** созданный объект мема с присвоенным id

### 2.2. `meme.read` - Получение информации о меме
- **Бизнес-правило:** Любой пользователь может просматривать любой мем
- **Входные данные:** id мема
- **Выходные данные:** полная информация о меме (включая imageUrl)

### 2.3. `meme.update` - Обновление существующего мема
- **Бизнес-правило:** Только автор мема может изменять свой мем
- **Ограничения:** Нельзя изменить id, authorId, createdAt, imageUrl
- **Входные данные:** id мема, новое название, новые теги
- **Выходные данные:** обновлённый объект мема

### 2.4. `meme.delete` - Удаление мема
- **Бизнес-правило:** Только автор мема может удалять свой мем
- **Возвращает:** подтверждение удаления (200 OK)

### 2.5. `meme.search` - Поиск мемов
- **Бизнес-логика:** Возвращает все публичные мемы, соответствующие запросу
- **Фильтры:**
   - По ключевым словам (поиск в title и tags)
   - Пагинация (limit, offset)
- **Сортировка:** по дате добавления (новые сверху)
- **Выходные данные:** список мемов с пагинацией

## 3. Бизнес-правила

1. **Авторизация:**
   - Просмотр и поиск — доступны без авторизации
   - Создание, редактирование, удаление — только для авторизованных пользователей

2. **Валидация тегов:**
   - Теги разделяются запятой
   - Максимум 10 тегов на один мем
   - Максимальная длина одного тега — 20 символов
   - Теги приводятся к нижнему регистру

3. **Управление файлами:**
   - При удалении мема файл изображения также удаляется с сервера
   - При обновлении мема изображение не меняется (только название и теги)

4. **Ограничения для всех пользователей:**
   - Максимум 1000 мемов на одного автора
   - Лимит 30 поисковых запросов в минуту

## 4. Бизнес-метрики успеха

1. **Скорость поиска:** 95% запросов должны возвращать результаты менее чем за 2 секунды
2. **Точность поиска:** Не менее 80% релевантных результатов при поиске по тегам
3. **Доступность:** Платформа доступна 99.9% времени (локально)
4. **Ограничения:**
   - Неавторизованные пользователи: 10 поисковых запросов в минуту
   - Авторизованные пользователи: 30 поисковых запросов в минуту
